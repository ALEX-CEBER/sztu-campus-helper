# 校园资讯模块 · 技术说明

> 模块位置：`web/news.js`（前端）+ `scripts/fetch_news.py`（抓取）+ `config/news.json`（配置）
> 数据文件：`data/news.json`（供 fetch 读取）/ `data/news.js`（内嵌，双击网页也能用）
> 数据源：深圳技术大学「校园通」<https://nbw.sztu.edu.cn/>

---

## 一、数据获取方式：HTML 解析（构建时抓取），不用浏览器直连

### 1.1 为什么不直接在前端 fetch 官网
| 障碍 | 说明 |
|---|---|
| **跨域（CORS）** | 学校站点未开放 `Access-Control-Allow-Origin`，浏览器 JS 直接请求会被拦截 |
| **反爬与频率** | 每次打开页面就抓官网，会被判定为异常流量，也拖慢首屏 |
| **稳定性** | 官网改版/临时故障会直接让页面空白，没有兜底 |

因此采用 **构建时抓取（build-time fetch）**：
```
脚本抓官网 HTML → 解析成结构化 JSON → 提交进仓库 → 页面读本地 JSON/内嵌数据
```
好处：浏览器零跨域、零外部依赖、断网可用、抓取频率完全可控（只有定时任务在抓）。

### 1.2 站点技术形态（已实测）
- 站点为**博达 CMS**（`index.vsb.css`、`/system/resource/js/*`），**服务端直出 HTML**，非 SPA，可直接解析；
- `robots.txt` 返回 404（未设置禁止规则）；
- 列表页示例：`https://nbw.sztu.edu.cn/`（通知）、`/xyxw.htm`（校园新闻），条目形如：

```html
<!-- 通知列表 -->
<div class="list">
  <a href="info/1021/52626.htm" target="_blank">
    <span>[学工]</span><span>关于开展《2027年省考指导》讲座的通知</span>
    <span class="arrow-right"></span><span>2026-10-28</span>
  </a>
</div>

<!-- 新闻列表 -->
<li><a href="http://www.sztu.edu.cn/info/1003/4512.htm" title="诺贝尔物理学奖得主，深技大开讲！" ...>…</a>
    <span style="float:right;">2026-10-26</span></li>
```

### 1.3 解析规则（`parse_list`）
1. 正则抓取所有 `<a href="…/info/{栏目}/{文章}.htm">`；
2. **标题**：优先 `title` 属性；没有则取 `<a>` 内文本（去掉 `[分类]` 与日期）；
3. **分类**：优先条目内的 `[科研]/[行政]/[学工]/[校园]` 标签，否则用栏目号映射
   （1003 校园新闻、1019 科研、1020 行政、1021 学工、1022 校园、1032 信息化）；
4. **时间**：条目内或紧随其后 260 字符内的 `YYYY-MM-DD`；
5. **链接**：相对路径补全为绝对地址。

### 1.4 字段定义（`data/news.json`）
| 字段 | 类型 | 说明 | 示例 |
|---|---|---|---|
| `title` | string | 标题（必填） | 关于举办"智行讲坛"（第四十期）的通知 |
| `date` | string | 发布日期 `YYYY-MM-DD` | 2026-10-28 |
| `category` | string | 分类（来自 `[标签]` 或栏目映射） | 校园 |
| `summary` | string | 摘要（详情页正文前 110 字，可为空） | 一、主题：发明有道… |
| `url` | string | 原文链接（新窗口打开） | https://nbw.sztu.edu.cn/info/1022/52624.htm |
| `column` | string | 栏目号（排查用） | 1022 |
| `source` | string | 来源模块名 | 校园通知 |
| `updated_at` | string | 本次同步时间（ISO，带 +08:00） | 2026-10-28T18:36:55+08:00 |
| `stale` | bool | 是否因抓取失败而回退到缓存 | false |
| `errors` | array | 本次抓取的错误列表 | [] |

## 二、更新机制：定时同步 + 缓存 + 重试 + 兜底

### 2.1 三条触发路径
| 方式 | 频率 | 说明 |
|---|---|---|
| **GitHub Actions** | 每 6 小时（`0 */6 * * *`）+ 手动触发 | `.github/workflows/sync-news.yml`，抓取后自动提交并重建 Pages 版 |
| **本地一键同步** | 手动双击 | `同步校园资讯.bat`：抓取 → 重建单机版 → 提交推送 |
| **离线演示** | — | `python scripts/fetch_news.py --offline` 只用缓存，断网也能演示 |

### 2.2 失败处理链（从强到弱）
```
① 源站请求失败 → 指数退避重试 3 次（2s/4s/6s）
② 仍失败 → 该源跳过，用另一个源的结果
③ 全部源失败 → 读取 data/news-cache.json（上次成功结果），标记 stale=true
④ 前端仍拿不到 → 使用内嵌 window.NEWS_DATA
⑤ 连内嵌数据都没有 → 展示"暂时获取不到 + 打开校园通"兜底卡片
```
> `data/news-cache.json` 只在抓取成功后写入，所以它永远是"最后一次好数据"。

### 2.3 性能与请求量
- 每次同步：2 个列表页 + 最多 12 个详情页（仅用于补摘要），共 ≤14 次请求；
- 请求间隔 `request_delay_seconds = 0.8s`，单次同步耗时约 12 秒；
- 前端只读本地文件，**不产生对官网的请求**，所以用户量再大也不会压垮源站。

## 三、界面与交互

- 顶部新增 **「办事问答 / 校园资讯」** 切换标签（与原有配色、圆角、阴影一致）；

- 顶部显示"更新于 2026-10-28 18:36 · 共 29 条"，异常时显示黄色"网络异常，以下为上次缓存"；
- 移动端（≤640px）：摘要限制两行、头部按钮换行、标签缩小，卡片单列。

## 四、可配置参数（`config/news.json`）

| 参数 | 默认 | 作用 |
|---|---|---|
| `sources[].url` | 官网地址 | 采集源，可增删；`enabled` 控制启停 |
| `max_items` | 30 | 最多保留条数（按日期倒序截断） |
| `timeout_seconds` | 15 | 单次请求超时 |
| `retries` | 3 | 失败重试次数 |
| `retry_backoff_seconds` | 2 | 退避基数（第 n 次等待 n×2 秒） |
| `request_delay_seconds` | 0.8 | 请求间隔（限频，建议不低于 0.5s） |
| `fetch_detail_summary` | true | 是否抓详情页生成摘要 |
| `detail_limit` | 12 | 每次最多抓多少个详情页 |
| `summary_length` | 110 | 摘要字数 |
| `user_agent` | 项目标识 | 便于源站识别来源 |

命令行覆盖：`--max 10`（临时限制条数）、`--offline`（只用缓存）。

## 五、合规与数据使用

1. **robots.txt 已检查**：站点未设置禁止规则（404）；本项目仅抓取公开页面。
2. **标识身份**：UA 为 `SZTU-Campus-Helper/0.3 (course project; +仓库地址)`，不伪装浏览器。
3. **限频**：固定 0.8s 间隔 + 单次 ≤14 请求 + 6 小时一次，远低于人工浏览强度。
4. **最小化存储**：只保存**标题、时间、分类、摘要（≤110 字）、原文链接**，不转载正文全文，不下载图片。
5. **保留来源**：每条卡片跳转原文，页面底部注明"资讯版权归深圳技术大学所有，本页仅用于课程学习"。
6. **可随时停止**：把 `sources[].enabled` 改为 `false` 即停止采集；删除 `data/news.*` 即下线模块。
7. **不商用、不二次分发**：课程作业用途，不用于任何商业场景。

## 六、验收自证（报告可直接截图）

```bash
# 1) 抓取并生成数据
python scripts/fetch_news.py
# 期望：解析到 16 条 / 21 条 → 写入 29 条

# 2) 查看数据结构
python -c "import json;d=json.load(open('data/news.json',encoding='utf-8'));print(d['count'], d['items'][0])"

# 3) 断网兜底演示
python scripts/fetch_news.py --offline

# 4) 重建单机版并双击查看
python scripts/build_standalone.py
```

**已知限制**
- 官网改版会导致解析规则失效 → 脚本会写入 `errors` 并回退缓存，需要更新正则；
- GitHub Actions 在境外网络，可能访问不到校内站点 → 以本地同步为主（见 `同步校园资讯.bat`）；
- 摘要来自正文前段，可能含"一、二、"等格式符，属正常现象。
