# AI 使用记录 · 第 1-2 周

> 用途：周报"AI 使用记录"栏的明细底稿。以后每周复制一份改名 `ai-log-weekNN.md`，
> 随手把"我问了什么 / AI 怎么处理的 / 我怎么判断"记下来，期末大报告的"AI 协作复盘"直接有素材。

## 使用方式
- **WorkBuddy**：规划、调研、写文档、生成立绘、整理数据、环境配置
- **CodeBuddy**：后续接管代码编写、跑命令、git 提交
- 铁律：AI 起草 → 我验收。涉及学校真实信息的一律标 `[待核实]` 由我核对。

---

### 记录 1 · 课题筛选
- **我的提问**：给出 5 个候选题，问哪些容易实现（附课程要求：7+1 报告、模型仅当晚开放、须关于学校且可含二次元）。
- **AI 的处理**：从"是否依赖生成算力""0 基础友好度""报告可演示性"三维度对比，
  指出"校内模型仅上课当晚开放"淘汰了小说影视化与校园电台，推荐校园办事问答，
  并给出离线优先架构与二次元看板娘构想。
- **我的判断**：采纳。理由充分——把不稳定的模型放在增强层，项目就不受接口时间限制。
- **产出**：定题、`docs/报告规划.html` + 桌面 PDF。

### 记录 2 · Git 环境
- **我的提问**：帮我下载部署好 Git，并写一份小白说明让 WorkBuddy / CodeBuddy 随时调用。
- **AI 的处理**：检测发现本机已有 Git 2.55 但零配置；完成全局配置（main/换行符/中文路径/凭据管理器）、
  生成 SSH 密钥、初始化仓库、首次提交，并写出 `docs/Git使用说明.md`（含急救包与 AI 调用约定）。
- **我的判断**：采纳。原以为要下载安装，实际是"装了没配"，说明环境问题要先检测再动手。
- **产出**：可用仓库 + Git 教程。

### 记录 3 · 原型搭建（AI 主动执行）
- **AI 的处理**：生成 6 类 31 条知识库 Markdown、解析脚本、原生检索网页、AI 生成看板娘立绘、
  README / .gitignore / AGENTS.md，并本地起服务器验证资源全部 200。
- **我的判断**：采纳，数据需后续核实（已保留 `[待核实]` 标记机制）。
- **产出**：v0.1.0，commit `519fccf`。

### 记录 4 · 缺陷定位与修复（本周最有价值）
- **我的提问**：为什么这个网站问不了东西？
- **AI 的处理**：定位两个真实缺陷——① 中文整句无分词导致必然零命中；② 数据文件路径在双击/预览环境加载失败。
  重写检索引擎（n-gram + 实词加权 + 同义词 + 停用词 + 阈值），加回归测试脚本，
  并把数据内嵌、产出单文件版。
- **我的判断**：采纳。命中率从"基本搜不到"提升到 20/20，首条结果全部正确。
- **产出**：v0.1.1，commit `0fd2259`，`web/search-core.js`、`scripts/test_search.js`、`dist/` 单机版。
